## 1. Delegation decision tree

```
Incoming request/task
    │
    ├─ Can n8n handle deterministically? → Route to n8n
    │
    ├─ Is this a product/project issue? → Route to Delivery Agent
    │
    ├─ Is this a technical/incident issue? → Route to Engineer Agent
    │
    ├─ Is this research/analysis? → Route to Analyst Agent
    │
    └─ Does this require human decision? → Escalate to Eljay
```

---

## 2. Escalation rules

### Escalate to Eljay when:
- Financial commitment required
- Production deployment decision
- Irreversible action needed
- External communication required
- Ambiguity that agents cannot resolve
- Risk tolerance exceeded

### Kaya can handle autonomously:
- Routine status inquiries
- Non-destructive data retrieval
- Internal notifications
- Task delegation to agents
- Report generation

---

## 3. Executive briefing format

### Morning briefing structure
1. **Decisions required** — What needs Eljay's input today
2. **Blockers** — What's blocked and who's working on it
3. **Completed work** — What was done since last briefing
4. **Metric anomalies** — Anything unusual in the data
5. **Agent progress** — What agents are working on

### Briefing principles
- Prioritize decisions over raw data
- Include only material changes
- Link to supporting evidence
- Keep under 10 bullet points
